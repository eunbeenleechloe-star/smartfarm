# 4일 예선 일정

## Day 1 — 계약과 병렬 개발
- PM: 공통 타입, 작물 기준, 점수 로직 확정
- API: 기상/토양/비료 API 호출 확인
- Front: 입력·결과 UI 뼈대
- 기획: 소개서 서비스 소개·문제·타깃 작성
- 종료 조건: mock 데이터로 `/api/analyze` 결과가 반환됨

## Day 2 — 실제 기능 연결
- 실제 API 정규화
- 적합도 점수와 위험 탐지
- 입력 → 결과 화면 연결
- 소개서 아키텍처·API·AI 활용 작성
- 종료 조건: 대표 시나리오가 처음부터 끝까지 동작

## Day 3 — 완성 및 제출물 제작 시작
- 결측·이상치·fallback 처리
- LLM 설명 연결 또는 템플릿 fallback
- 결과 UI 다듬기
- 소개서 완성
- 1분 영상 스토리보드와 1차 녹화
- 종료 조건: 기능 동결

## Day 4 — 검증과 제출
- 새로운 기능 추가 금지
- 5개 작물 선택 테스트
- API 실패 테스트
- 최종 화면 녹화·영상 편집
- 소개서 PDF 변환
- 제출 파일과 링크 최종 확인
